## Project 1: Active Directory & Azure Server Lab

Built a Windows Server domain controller on Microsoft Azure to practice real-world Active Directory administration, the same technology used to manage users and permissions across corporate networks.

### What I did
- Deployed a Windows Server 2025 VM on Microsoft Azure
- Installed the Active Directory Domain Services (AD DS) role
- Promoted the server to a Domain Controller, creating the domain `karabo.local`
- Built an organizational unit (OU) structure: IT, Finance, and HR departments
- Created test users and security groups for each department
- Configured a Group Policy Object (GPO) enforcing password complexity requirements on the IT department, and confirmed it worked by testing a weak password against it

### Tools used
- Microsoft Azure (free tier)
- Windows Server 2025
- Remmina (RDP client, connecting from Linux Mint)

### What I learned
- How Active Directory structures users, departments, and permissions in a real company environment
- How Group Policy enforces rules across an organization, and how to verify a policy is actually working
- Remote server administration from a Linux machine
- Basic cloud infrastructure management using Azure
